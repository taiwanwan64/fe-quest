# FE QUEST v347 — 外部βドライラン手順

対象: 最初の **10〜30人** の外部βを始める直前の運用確認  
Production baseline: **v345**  
目的: テスターを招待する前に、「初回設定 → 実力診断 → 今日の学習 → 学習継続 → データ保護 → フィードバック」の一連の体験が切れずにつながっていることを確認する。

> この文書は外部βを自動で開始するものではありません。実際の招待先・人数・開始日は人が決めます。

## 1. 招待時に伝えるもの

- FE QUEST本番URL: `https://taiwanwan64.github.io/fe-quest/`
- プライバシーポリシー: `https://taiwanwan64.github.io/fe-quest/privacy.html`
- フィードバック / 不具合報告: GitHub Issues の「βフィードバック / 不具合報告」テンプレート
- クラウド同期は任意であり、ログインしなくても学習できること
- 公開Issueにメールアドレス、Magic Link、認証トークン、JSONエクスポート全文、localStorage / IndexedDB全文を貼らないこと

## 2. 初回利用ドライラン

新しいブラウザプロファイル、プライベートブラウズ等の「学習履歴がない状態」で確認する。

1. FE QUESTを開く。
2. 受験予定日と1日の学習時間を設定する。
3. 「今日の計画を作る」を押す。
4. 今日の計画が表示されることを確認する。
5. 実力診断を開始し、12問を最後まで回答する。
6. 診断完了後、ホームへ戻り、そのまま「今日の学習」の次の未完了タスクへ進めることを確認する。

確認ポイント:

- 受験予定日を未入力のまま進めない。
- 過去の日付を受験予定日にできない。
- 設定保存に失敗した場合に、学習開始済みのように見せない。
- 初回設定で作られた今日の計画と、ホームの「今日の学習」が同じ計画を参照する。
- 診断終了後に次に何を押すか迷わない。

## 3. 日常学習ドライラン

1. ホームの「今日の学習を始める / 続きから再開」を押す。
2. 次の未完了タスクが開くことを確認する。
3. 学習を1件完了する。
4. ホームへ戻り、完了数と次のタスクが更新されることを確認する。
5. 科目Aだけでなく、科目Bが今日の計画に含まれる状態でも同じ導線を確認する。
6. 模試・科目Bの結果画面から、次の学習へ戻る主導線が残っていることを確認する。

## 4. 学習成果表示ドライラン

「学習分析」で次を確認する。

- 最近の学習レポートが表示される。
- 保存済み回答が少ない場合に、無理に「伸びた」と断定しない。
- 「試験までのペース」が、既存の受験日・残り学習量・最近の学習ペースを使って表示される。
- 直前7日では追い込みを促さず、既存の45 / 30 / 15 / 10分テーパリングを優先する。
- 「試験までのペース」や準備度を合格確率として表示しない。

## 5. 保存・クラウド同期ドライラン

クラウド同期を使わない状態と、明示的に有効化した状態の両方を確認する。

### 同期なし

- ログインせずに学習できる。
- 学習履歴が端末内に保存される。
- JSONエクスポートと復旧センターが利用できる。

### 同期あり

- Magic Linkでログインできる。
- クラウド同期を明示的に有効化するまで、端末データを送信しない。
- 別端末との競合時、自動上書きせず「この端末 / クラウド」のどちらを残すか選べる。
- ログアウトしても端末の学習データは残る。
- アカウント削除ではクラウド上の学習データを削除し、端末データは自動削除しない。

## 6. 不具合報告ドライラン

βフィードバック用Issueテンプレートを1件、**送信せず入力だけ**して確認する。

最低限、次を記録できればよい。

- 何をしていたか
- 実際に起きたこと
- 期待していたこと
- 再現手順
- FE QUEST表示バージョン
- 大まかな端末 / ブラウザ
- 学習データやクラウド同期への影響有無

機微情報や学習データ全文は要求しない。

## 7. β開始後の確認

`docs/BETA_MEASUREMENT_PLAN_v346.md` に従い、最初のコホートではアプリへ第三者Analyticsを追加せず、必要最小限の手動確認を行う。

- 1日目: 初回設定と「今日の学習」開始で詰まらなかったか
- 3日目: 次に何を勉強するか迷わず再開できたか
- 7日目: 継続利用したか / 計画が役に立ったか
- 30日目: 継続したか / FE QUESTが「次の一手を決める」価値を感じたか

中心質問は次の2つとする。

1. 「今日の学習」から実際に学習を始めたか。
2. 「次に何を勉強するかを自分で考える負担が減ったか」。

## 8. Go / No-Go

外部βの招待を始める前に、少なくとも次を満たす。

- productionが既知の安定版である。
- 初回設定 → 診断 → 今日の学習の主導線が切れていない。
- 日常学習の次タスク導線が切れていない。
- 科目B / 模試結果から次の学習へ戻れる。
- profile schema、保存、復旧、クラウド同期の既存契約に回帰がない。
- `privacy.html` とβフィードバック導線が現行実装と一致する。
- 自動トラッキングを追加していない。

上記をCIで静的・runtime契約として確認し、最後に実ブラウザで1回だけドライランしてから、人がβ開始を判断する。
