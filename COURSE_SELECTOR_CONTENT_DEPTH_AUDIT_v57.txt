FE QUEST v57 — COURSE SELECTOR / CONTENT DEPTH AUDIT

Course selector bug:
The Subject B tab could become active while Subject A remained visible.
Cause: v54-v56 toggled a generic "hidden" class, but the course panels had no generic display:none rule.

Fix:
- native hidden property and attribute
- explicit course-panel-hidden display:none!important fallback
- role=tab / tabpanel
- aria-selected / aria-hidden
- direct click handlers
- keyboard left/right switching
- last selected subject persisted

- 21/21 chapter learning guides
- guide = goal + focus + formulas/decision axes + caution
- 99/99 Core A topics get a worked-example page
- calculation/scenario/trace/interpretation preferred where available
- high-yield topics may show two worked examples
- Core A: 99 x 6 = 594 pages

Flow:
chapter guide -> overview -> points -> concrete example -> worked example
-> discrimination -> mini check -> topic practice -> chapter check -> mock
