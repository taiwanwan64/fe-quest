FE QUEST PWA v105
Distractor structure / answer-cue audit

Purpose
- Continue v103-v104 distractor-quality work.
- Address a subtler clue than "○○だけする": the correct choice being the only option that lists several relevant factors, while distractors are short or single-focus.
- Learners should choose the answer from subject-matter reasoning, not from "the most comprehensive sentence is probably correct".

Changes
1. Security case questions: 7 steps rewritten
- ransomware: investigation evidence
- suspicious login: verification evidence
- risk management: treatment decision factors
- XSS: impact investigation evidence
- data exfiltration: scope/path investigation evidence
- password hash leakage: incident response
- patch management: temporary risk treatment

2. Option-form symmetry
- Where the answer used a three-part list, distractors were rewritten into comparable multi-part bundles.
- Distractors now represent plausible but differently targeted evidence, priorities, or controls.
- Removed the pattern where "など" appeared only in the correct answer for judgment/security questions.

3. Question stems sharpened where needed
- Some stems now specify the decision objective (e.g. identifying affected users/time period, tracing intrusion route/external communication), so multiple realistic-looking choices can coexist while one remains the best answer.

Regression / validation
- Subject A base bank: 160 questions, unchanged.
- Subject A linked bank: 390 questions, unchanged.
- Subject A challenge bank: 160 questions, unchanged.
- Subject A total: 710 questions, all answer keys unchanged.
- Subject B algorithm exercises: 20, unchanged.
- Subject B compound sets: 15, unchanged.
- Security: 15 cases / 45 questions; exactly 7 steps changed; answer keys unchanged.
- Correct-only comprehensive-list cue flags: 0 across all Subject A judgment questions + all security case questions.
- Correct-only "など" cue flags: 0 across the same set.
- v103/v104 giveaway-cue and incomplete-action checks retained.
- Profile Schema: v5 unchanged.
- MAIN_JS_SYNTAX_OK
- SW_SYNTAX_OK
- MANIFEST_JSON_OK

Design rule going forward
- Do not make the correct answer visually or rhetorically "more complete" than every distractor.
- Keep option structure and information density comparable.
- Wrong options should be plausible packages of evidence/actions that fail because of target, priority, timing, scope, or mechanism.
