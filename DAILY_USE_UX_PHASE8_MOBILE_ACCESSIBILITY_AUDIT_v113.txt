FE QUEST PWA v113
日常利用UX監査 第8段階（スマホ操作 / アクセシビリティ / BIT先生干渉低減）

目的
- 320〜430pxのスマートフォンで、画面全体の横スクロールを発生させない。
- 毎日触る主要操作を、指で押しやすいサイズへ統一する。
- BIT先生を残しつつ、本文や主要CTAを覆う面積を減らす。
- アイコンだけの操作、画面切替、状態通知、ダイアログを支援技術でも理解できるようにする。
- 学習問題・教材・保存形式・試験直前調整は変更しない。

1. スマホのタップ領域を横断統一
- max-width:720px で button と details > summary の最小高さを44pxに統一。
- 戻るボタンは幅・高さとも44px固定、flex-shrinkで細くならないようにした。
- 科目Bの問題番号ナビゲーションも44×44pxへ拡大。
- アプリ通知の閉じるボタン、BIT先生の閉じる/送信ボタンも44px以上を確保。
- 320px幅の静的レイアウト検証で、表示中の button / details summary に44px未満の要素が0件になることを確認。

2. BIT先生の固定ボタンを小型化
旧:
- スマホでも「🤖 BIT先生」という横長の固定ボタン。

v113:
- スマホでは50×50pxの丸い「🤖」ボタンへ変更。
- アクセシブル名は「BIT先生に質問する」を維持。
- 左下配置を維持しつつ、本文・回答欄・右寄せCTAを覆う面積を削減。
- BIT先生を開いている間は固定ボタン自体を非表示にし、重複操作を防止。

3. BIT先生をダイアログとして整理
- role="dialog" / aria-modal="true" / aria-labelledby / aria-describedby を追加。
- 閉じている間は aria-hidden="true" + inert とし、画面外のチャットUIへTab移動しない。
- 開くと inert を解除し、aria-expandedをtrueへ更新、入力欄へフォーカス。
- 閉じるとaria状態を戻し、開く前のボタンへフォーカスを返す。
- Escapeキー、背景タップでも閉じられるようにした。
- チャット履歴は role="log" + aria-live="polite" とした。
- 送信ボタン、閉じるボタン、入力欄に明示的なアクセシブル名を追加。

4. ナビゲーション / 画面状態のARIA同期
- 左/下ナビに role="navigation" と aria-label="メインナビゲーション" を追加。
- 現在の主タブへ aria-current="page" を付与。
- showScreen() で activeクラスと各screenの aria-hidden を同時更新。
- ナビの絵文字は aria-hidden="true" とし、スクリーンリーダーには「ホーム」「学習」「演習」「計画」という名称だけを読ませる。

5. アイコンだけの戻る/終了操作を明確化
- 「←」だけの20個の戻るボタンに aria-label="前の画面に戻る" を付与。
- 「×」で演習を抜けるボタンには aria-label="終了して戻る" を付与。
- BIT先生の×、チャット送信➤にも個別のaria-labelを追加。

6. フォーカス表示 / 動きを減らす設定
- button / input / select / textarea / summary / tabindex要素へ統一した :focus-visible を追加。
- キーボード操作時に現在位置が分かる3pxアウトラインを表示。
- prefers-reduced-motion: reduce に対応し、アニメーション/トランジションをほぼ停止。

7. 状態通知
- トーストを role="status" + aria-live="polite" に変更。
- オフライン表示も role="status" + aria-live="polite" に変更。
- 視覚表示だけでなく状態変化を支援技術でも認識できるようにした。

8. PWA追加案内
- iPhoneへの追加案内を role="dialog" / aria-modal="true" 化。
- 開いたときは閉じるボタンへフォーカス。
- 閉じたときは元の「追加方法を見る」へフォーカス復帰。
- Escapeキー、背景タップで閉じられる。

9. 320〜430px 横断レイアウト検証
Chromiumを使い、JavaScriptを除いた静的DOM/CSSの全main screenを順番にactive化して検証。

幅320px:
  ページ横overflow 0画面
  44px未満の表示中操作要素 0件
幅375px:
  ページ横overflow 0画面
  44px未満の表示中操作要素 0件
幅390px:
  ページ横overflow 0画面
  44px未満の表示中操作要素 0件

  44px未満の表示中操作要素 0件

※ code/table等、意図的に内部スクロールする専用コンテナはページ横overflowとは別扱い。

10. ブラウザ実行確認の範囲
- Chromium + page.set_content() ではBIT先生の開閉処理を実行でき、
  開く: aria-hidden=false / inert解除 / aria-expanded=true / chatInputへfocus
  閉じる: aria-hidden=true / inert復帰 / aria-expanded=false / aiFabへfocus復帰
  を確認。
- 一方、この実行環境では file:// と http://127.0.0.1 のページ遷移が ERR_BLOCKED_BY_ADMINISTRATOR となる。
- page.set_content() ではlocalStorageが許可されず、FE QUEST全体のwindow.FEQUEST_BOOT_OKまで到達できない。
- よって「実URL/実PWAでのフルE2E成功」とは扱わず、静的レイアウト + DOM/JS契約 + ダイアログ単体実行までを今回のブラウザ検証範囲とする。
