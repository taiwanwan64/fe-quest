FE QUEST v58 — UI LANGUAGE / VISIBILITY AUDIT

表示不具合
- .hidden { display:none!important } を全体ルールとして追加。
- 旧機能で hidden クラスを付けても消えなかった表示をまとめて修正。
- 科目B総合実戦のセキュリティ欄は native hidden も併用。
- 擬似言語問題では警告アイコン・判断材料/ログ欄を完全非表示。
- セキュリティ問題へ切り替えた場合だけ表示。

学習コース
- 科目A CORE COURSE -> 科目A コアコース
- SUBJECT B COURSE -> 科目B コアコース
- A/Bの見出しカードを同一 course-overview コンポーネントへ統一。
- padding / min-height / border-radius / 右側情報欄の寸法を統一。
- Aは進捗%、Bは4ステップを右側に表示。
- Aは緑、Bは紫で区別するが形状は同じ。

主なUI表記変更
- PROGRAM TRACE -> プログラムトレース
- SECURITY SCENARIO -> セキュリティ シナリオ
- EVIDENCE / LOG -> 判断材料・ログ
- DECISION -> 判断
- PSEUDOCODE -> 擬似コード
- CURRENT STATE / STATE -> 現在の状態 / 状態
- FULL/HALF MOCK -> フル/ハーフ模試
- QUESTION MAP -> 問題マップ
- QUESTION BANK -> 問題バンク
- VARIANT REVIEW -> バリエーション復習
- NEXT PRIORITY -> 次の優先項目
- BEST -> ベスト
- CLEAR -> クリア
- TODAY -> 今日
- RETRY -> 再挑戦

意図的に英語を残すもの
- FE QUEST（アプリ名）
- SQL / TCP / UDP / DNS / CPU / LIFO / FIFO 等、試験で表記自体を覚える専門用語・略語
- SQLや擬似コード内の構文
- 略語の後ろに併記する正式名称（ユーザー指定）
