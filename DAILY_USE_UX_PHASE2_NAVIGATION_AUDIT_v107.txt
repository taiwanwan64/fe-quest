FE QUEST PWA v107
Daily-use UX audit — Phase 2: navigation hierarchy

Goal
Reduce daily navigation decisions without deleting advanced functions. Separate frequently used destinations from screens that are only needed for analysis, progress review, or full mock exams.

Changes
1. Primary navigation reduced to four destinations
- ホーム
- 学習
- 演習
- 計画

Previously, 苦手 / 範囲 / 模試 were equal-level navigation destinations. Those remain fully available but no longer compete for attention in the always-visible navigation.

2. Practice-related secondary screens moved under 演習
- 苦手分析
- 科目A 模試

The 問題演習 screen now includes two compact secondary shortcuts near its top. Normal daily practice modes remain the primary content of the screen.

3. Progress-related secondary screens moved under 計画
- 学習分析
- 試験範囲の進捗

These screens are useful for checking status, but are not necessary every time the learner opens the app. They are now accessible from the planning screen as compact shortcuts.

4. Back navigation aligned with information hierarchy
- 模試 → 演習
- 苦手分析 → 演習
- 試験範囲カバレッジ → 計画
- 学習分析 → 計画 (existing behavior retained)

5. Parent tab remains highlighted on secondary screens
- 苦手分析 / 模試 highlight 演習
- 学習分析 / 試験範囲カバレッジ highlight 計画
- Lesson / Subject B work continues to map to 学習

6. Smartphone bottom navigation
The always-visible mobile navigation now has four equal daily-use destinations instead of seven competing items. This also improves tap-target spacing and reduces label crowding.
