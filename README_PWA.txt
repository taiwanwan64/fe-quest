FE QUEST PWA v16

ADAPTIVE PRESCRIPTION ENGINE:
- 知識不足 / データ不足 → 関連教材
- 計算ミス → 計算ドリル 8問
- 読み違い → 条件語ドリル 8問
- 2択で迷う → 比較ドリル 8問
- 時間不足 / 模試平均回答時間が長い → 15分スプリント 10問
- 繰り返し誤答 → 繰り返し誤答つぶし 8問

連携:
- HOME「今日のクエスト」の新規学習枠を必要に応じて処方ドリルへ置換
- 問題画面に「今日の処方ドリル」
- 苦手分析に「FE QUESTの処方」
- 処方ドリル完了で今日のクエストも完了
- 既存の習熟度・XP・間隔反復へ結果を反映

安全な初期化:
- 初回HOME描画時は処方エンジンを使わない
- 苦手分析用データ構造の初期化後に FEQUEST_RX_READY=true
- その後HOMEを再描画して適応処方へ切替
- v15で修正した模試起動TDZ不具合も継続修正済み

検証:
- node --check
- DOM模擬環境で起動
- HALF MOCK開始
- 苦手分析描画
- 自動処方生成
- HOME今日のクエスト生成
- 計算処方ドリル開始

問題・教材はFE QUESTオリジナル。
参考書は章構成・重要テーマ・難易度感の参考に限定。
