FE QUEST PWA v49

受験予定日連動の学習ペース機能

- 残り日数
- FE QUEST内の残り推奨学習量
- 最近の記録学習ペース
- 必要ペース
- 今のペースでの完了見込み
- 間に合う / 少し不足 / 要加速
- 今日の自動目標時間

自動調整ONでは、必要ペースが標準時間を超える場合に
今日の目標を5分単位・最大120分まで引き上げます。
休んだ日が増えれば、翌日以降に再計算されます。

試験日が近づくにつれて、
新規学習を減らし、復習・科目B・総合チェックを増やします。

表示される完了見込みはFE QUEST内の推奨メニューについての目安であり、
基本情報技術者試験の合格確率ではありません。
