FE QUEST PWA v26

v26の主な変更

1. IoT進行表示
- 1ページ目の全体図では「現在」「STEP」を表示しない
- 2ページ目の操作開始時から「現在」を表示
- STEP n / total は操作ボタンだけに表示
- 図の下は「現在：センサ」のような現在位置だけを表示
- 3ページ目の静的説明も進行表示なし

2. 全76問の品質監査
監査対象:
- 問題文
- 正解選択肢
- 誤答選択肢
- 解説
- ヒント

結果:
- 76問すべて監査
- 41問を内容面で修正
- 35問は内容を確認して維持
- 全IDを維持し、既存の学習履歴と互換

主な改善:
- 不自然・簡単すぎるダミー選択肢を、同分野のもっともらしい誤答へ変更
- ほぼ同じ内容だった重複問題を別論点・別角度へ変更
- 計算問題の途中式を解説へ追加
- 解説で「なぜ他ではなくこれなのか」が分かるように補強
- ヒントが答えをそのまま言い過ぎないよう調整
- 問題文の曖昧さを減らす

重複を減らした例:
- WBSの重複 → 片方をEVMへ
- SLAの重複 → 片方を稼働率計算へ
- 知的財産の重複 → 商標権へ
- マーケティングの重複 → 4Pへ
- 信頼性の重複 → 並列システムへ
- システム監査の重複 → 監査証拠へ
