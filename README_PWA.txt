FE QUEST PWA v18

v18: ADAPTIVE MEMORY ENGINE

従来:
- streak 1 → 3日
- streak 2 → 7日
- streak 3 → 14日
- 以後30日
という固定間隔。

v18:
各問題に「stability（記憶間隔）」を持たせ、回答結果に応じて変化させます。

主なルール:
- 初回で正解
  → stabilityを伸ばす
- 速く正解
  → わずかに長め
- 時間をかけて正解
  → 伸び幅を小さめにする
- 最初は誤答し、RETRYで正解
  → 翌日復習。正答として間隔を伸ばさない
- 誤答
  → stabilityを短縮し翌日復習
- 繰り返し誤答
  → review urgencyを上げる
- 模試の正誤と問題別回答時間も同じ記憶モデルへ反映

記憶保持率:
- stability = 「推定保持率が約80%まで下がる日数」と定義
- 経過日数とstabilityから保持率を推定
- 80%未満、または復習期限到達で復習キューへ
- これはFE QUEST独自の学習用ヒューリスティックで、医学的・心理学的な測定値ではありません

新UI:
- HOME「今日の復習候補」を固定表示から動的表示へ
- 忘却リスクの高い論点TOP3
- 学習計画「記憶の健康状態」
  - 推定平均保持率
  - 安定
  - そろそろ
  - 要復習
- 7日間の復習予報
- 問題解説に「次回復習日・記憶間隔」を表示
- 今日の復習は忘却リスク・期限超過・繰り返し誤答から優先順位付け

データ移行:
- v17以前のqStatsを自動移行
- 既存のstreakから初期stabilityを推定
- localStorageの既存進捗は維持

教材・問題:
- 問題・教材はFE QUESTオリジナル
- 添付参考書は章構成・重要テーマ・難易度感の参考に限定
- 参考書独自問題は転載しない

検証:
- node --check
- Node VMで起動
- HALF MOCK開始
- 適応記憶更新
- 復習キュー
- 7日予報
- 記憶ダッシュボード
- 実ブラウザ自動試験も試行
  - この実行環境では Chromium が localhost / file URL を管理者ポリシーで遮断するため実施不可
  - 代わりにNode VMで起動・模試・記憶更新・復習予報・ダッシュボードまで実行時検証
  - GitHub Pages上での最終操作確認は公開後に行う
