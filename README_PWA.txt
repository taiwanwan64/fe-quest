FE QUEST PWA v15

重要修正:
- v12〜v14に含まれていた起動時JavaScriptエラーを修正。
- 原因:
  オートマトン等の教材状態変数を、let宣言より前に初期化していたため、
  Temporal Dead Zone (TDZ) の ReferenceError が発生。
- このエラーでスクリプト実行が途中停止し、
  後半にある科目A MOCKの開始ボタンへイベントが登録されていなかった。
- v15では宣言順を修正。

検証強化:
- node --check による構文チェック
- DOMを模擬したNode VMでアプリの初期化を実行
- 同VM内で startMock('half') を実行し、模試開始処理が例外なく動くことを確認
- window.FEQUEST_BOOT_OK を追加

v15新機能: 苦手分析の本格化
- 8分野を「優先度」順に表示
- 習熟度
- 通常演習の正答率
- 直近模試の平均回答時間
- 繰り返し誤答論点数
- 主な誤答理由
- 誤答理由分布
- 繰り返し誤答TOP
- 時間がかかった模試問題
- 分野ごとの改善アドバイス
- 「この分野を10問」ボタン
- 「教材を見る」ボタン
- 優先度はFE QUEST独自の学習用ヒューリスティックで、合格確率ではない

問題ポリシー:
- 参考書独自問題は転載しない。
- FE QUESTの問題・類題・教材例はオリジナル。
- 実際の試験公開問題を使用する場合のみ「公開問題」と明示して別管理。
