FE QUEST PWA v23

主な変更

1. 不要な強制操作を削減
- ウォーターフォール / アジャイル比較はクリック不要に変更
- 2枚のカードを最初から見比べられる静的比較へ戻した
- 「操作すること自体に学習上の意味がある場面」だけをインタラクティブとして残す

2. 現在位置が光るアニメーションガイド
STEP式の図解で現在位置を青く発光表示。
通過済みは淡い緑 + ✓ 表示。
次のSTEPで発光位置が移動する。

対応:
- CPU命令サイクル
- IoT
- デジタル署名
- システム開発工程
- テスト工程
- OS / CPUスケジューリング
- ファイルシステム
- 利益計算

3. 操作ガイド
上記の逐次型教材では
「青く光っている箇所が現在位置です」
と明示。

4. アクセシビリティ
prefers-reduced-motion が有効な環境では
点滅アニメーションを停止し、静的ハイライトのみ表示。

5. v22までの機能を継続
- 自然な問題選択肢
- 図解レイアウト安定化
- Adaptive Memory
- VARIANT REVIEW
- ACTIVE RECALL / RETRY
