FE QUEST PWA v8

v8の主な追加:
科目B TRACE LABを本格化し、6つのオリジナルトレース演習を追加。

1. ループで合計（基礎）
2. 配列の最大値（基礎）
3. 線形探索（標準）
4. スタック操作（標準）
5. 再帰呼出し factorial(4)（標準）
6. 木の深さ優先探索（応用）

機能:
- 擬似コードを1行ずつハイライト
- 変数値をリアルタイム表示
- 配列の現在位置を可視化
- スタック / コールスタックを可視化
- 木の訪問済みノードと出力順を可視化
- 途中で「次の値」を予測するPREDICT問題
- クリア状況保存
- XP・アルゴリズム習熟度へ反映

問題・教材ポリシー:
- 添付参考書は科目Bの構成、扱うテーマ、難易度感の参考としてのみ使用。
- v8の擬似コード、具体例、変数、問題、トレース手順、解説はFE QUEST用に新規作成。
- 参考書独自の問題は転載しない。
- 実際の試験で出題された公開問題を将来収録する場合は「公開問題」と明示して区別する。
