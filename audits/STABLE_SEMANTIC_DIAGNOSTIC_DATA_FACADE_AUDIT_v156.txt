COMPATIBILITY BACKING POLICY
The following six historical globals intentionally remain in production as backing storage in v156:
- V148_EXTRA_UI_CONTRACTS
- V149_LEGACY_ASSERT_INVENTORY
- V150_CI_ONLY_SENTINEL_GROUPS
- V150_CRITICAL_CURRICULUM_SPEC
- V151_RELEASE_SENTINEL_SPEC
- V152_LEGACY_FIXTURE_SPEC

Why they remain:
- Existing stable helper functions in app/runtime-current-diagnostics.txt still resolve some of these global names at call time.
- Deleting them in v156 would break the already-stable helper runtime even though the new v156 contract code itself can use semantic keys.
- v156 therefore establishes the stable data API first and defers physical backing-global removal until helper dependencies are rewired.
