High-trace-load rubric
----------------------
An item is marked high-trace-load for this audit when it requires sustained reconstruction of dependent state rather than a local one-line operation. The manual rubric requires:
1. at least three dependent state transitions, or a non-linear recursive/data-structure traversal;
2. an answer that depends on the sequence of state changes rather than one isolated operator or one direct blank; and
3. multiple evolving variables or a structured state such as an array, queue, pointer chain, search interval or recursion tree.

Selector gap
------------

Because seen count is the first candidate priority, an exposure history can legitimately make a set of compact items the preferred candidates in each compatible pool. Format diversity does not prevent this because it is evaluated after seen count.
