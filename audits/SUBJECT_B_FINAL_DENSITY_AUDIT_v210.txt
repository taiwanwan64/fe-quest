Expansion decision
------------------
Approve exactly three original FE QUEST additions for v211. Do not rewrite or replace an existing item and do not change the selector.

Priority 1 — オブジェクト指向 / 標準 / sustained trace
Add one item that requires tracking multiple object references and method-driven state changes across at least three dependent transitions before determining a final state. Keep the difficulty at 標準: the challenge should come from careful state tracking, not advanced language-specific syntax.

Priority 1 — ビット列 / 応用 / sustained trace
Add one item that requires following a bit state through multiple dependent mask/shift/logical-operation transitions. The answer must depend on the sequence of state changes rather than one isolated AND/OR/XOR operation.

Priority 2 — 木構造 / 標準 / sustained trace
Add one item using a small tree and explicit evolving traversal state. It should require reconstruction of several dependent steps while avoiding the pointer depth or recursive branching expected of the existing applied tree items.

Why these three
---------------
The first two close the only missing same-domain/same-level high-trace cells used by the default final-session domain slots. The tree-standard addition strengthens the weakest standard domain cell (currently one standard item) while increasing standard sustained-trace diversity.
After the proposed additions, the expected pool is 43 items and the manually classified sustained-trace inventory would become 15: 標準5 / 応用10. All ten default domain-level slots would then have at least one compatible sustained-trace candidate.

Not approved now
----------------
Do not add a 探索・整列 / 標準 item merely to make the table symmetric. Final practice intentionally treats 探索・整列 as an applied default domain, and the attached sources do not justify changing that difficulty boundary.
Do not raise the sustained-trace floor above four.
Do not change final 20=algorithm16+security4, algorithm 標準8/応用8, ten-domain coverage, security 2-log/2-non-log, exposure fairness, review behavior or saved-state IDs.
