Cleanup / release policy
------------------------
Temporary v170 validation workflow and tools are removed before main is advanced. Cleanup must not modify app/, the v170 regression fixtures, audits/LEARNING_COMPACTION_AUDIT_v170.txt, index.html, manifest.webmanifest, or sw.js. This formal validation audit is retained as release evidence.

Next architecture direction
---------------------------
v170 proves that the 47-file learning patch chain can be represented by one production learning module without changing a single generated HTML byte or canonical runtime state. A future architecture pass can now treat app/learning-patches-v170.txt as the stable active learning source while retaining the 47 original fragments only as provenance/regression inputs, then separately evaluate whether base-v131 and the stable bundle should be materialized into a simpler standalone production source. That later step should again require byte/runtime equivalence before changing production assembly.
