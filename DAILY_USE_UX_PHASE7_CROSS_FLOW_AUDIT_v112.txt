FE QUEST PWA v112
日常利用UX監査 第7段階（初回 / 起動 / 翌日再開 / 設定 / PWA案内の横断整理）

目的
- 初回ユーザーに複数の主導線を同時提示せず、最初に何をすべきか迷わせない。
- 毎日使う既存ユーザーのホームに、インストール案内など学習以外の表示を常駐させない。
- アプリを翌日に開いたとき、前日の分析・模試・詳細画面に取り残されず、新しい「今日の学習」から始められるようにする。
- 設定・復旧など低頻度操作への導線は残しつつ、通常の学習導線と競合させない。
- 学習問題・教材・保存形式は変更しない。

1. 初回ホームを1アクションへ整理
- diagnosticCompleted=false の間、通常の「今日の学習」カードと復習候補をホームで一時的に隠す。
- ホーム上部には「12問・3〜5分ほど」の実力診断だけを主導線として表示。
- 初回見出しも「最初に現在地を確認しましょう」へ切替え、通常ユーザー向け説明との食い違いを解消。
- 未診断なのに試験準備度0%を見せることを避け、デスクトップ右欄の準備度カードも診断完了まで非表示。

2. 診断開始までの余分な1タップを削減
- ホームの「実力診断を始める →」から、診断説明画面をもう一度挟まずQ1へ直接進む。
- 診断画面内の説明ページ自体は残し、再利用可能な構造を維持。
- 診断結果の主ボタンを「診断結果を反映して学習を始める →」に変更。
- 結果確認後はホームへ戻るだけでなく、その日の最初の未完了学習タスクを直接開始する。
- 診断結果の「60分を効率よく使う」という固定文言を廃止し、現在の学習時間設定・試験直前調整で計算された effectiveStudyMinutes() に連動。

3. PWA追加案内を毎日のホームから撤去
- 「FE QUESTをアプリとして使う」カードをホームから削除。
- 「計画 → 進捗・設定の詳細 → アプリ・データ」内へ移動。
- 既にホーム画面PWAとして起動している場合は従来どおり自動非表示。
- iPhone Safari等で必要な場合だけ「追加方法を見る」から既存の案内モーダルを開ける。
- 学習開始前にインストール作業を促す表示が割り込まない構成にした。

4. 翌日は必ずホームから開始
- UI状態に updatedAt が保存されている既存機構を利用し、同じローカル日付か判定する uiStateIsToday() を追加。
- 日付が変わっていたら、前日の画面に復元せずホームを表示。
- 新しい日の復習期限・今日の計画を最初に確認できる。
- 100分科目B総合実戦は既存のexpiresAt付き再開情報を優先するため、進行中タイマーの安全な再開機構は維持。

5. 同日再開は「主ハブ / 途中教材」だけを保つ
SAFE_RESUME_SCREENS:
  home / map（学習） / problems（演習） / plan（計画）
- 苦手分析、模試メニュー、試験範囲、学習分析などのサブ画面を閉じた場合、親ハブを再開位置として使う。
- lesson は従来どおり同日なら教材ページ位置を復元。
- trace は科目Bトップを含む学習ハブへ戻す。
- 「昨日分析画面を見たので、今日も分析画面から起動」という日常利用上の迷いを防ぐ。

6. 設定ボタンの実動作を修正
- v111では計画画面が compact 状態のため、設定ボタンで learningSettingsCard へscrollIntoViewしても対象が非表示の可能性があった。
- setPlanDetailsOpen(open) を追加し、詳細領域の開閉処理を一元化。
- 設定ボタンは計画画面を開く → 詳細を開く → 学習設定へスクロール、の順で実行。
- 計画画面の「進捗・設定の詳細を表示」ボタンも同じ関数を使用。

7. デスクトップ右欄の固定ダミー表示を撤去
旧表示:
  「🔥 6日連続」
  「⏱ 0 / 60分」
  「⭐ +0 XP」
- 実データと連動していないため削除。
- 代わりに、その日の完了数 / 計画時間 / 次タスクを renderDailyPlan() と同期して表示。
- 「続きから再開 →」から次の未完了タスクへ直接進める。
- 初回診断前は「実力診断を始める →」へ自動切替。

10. 実ブラウザ確認について
- Chromium headlessで390×844相当のローカル画面キャプチャを試行した。
- この実行環境ではChromiumプロセスが終了せずタイムアウトしたため、スクリーンショット取得・実ブラウザE2E成功とは扱っていない。
- そのため今回の保証範囲は、HTML/CSS/JavaScript契約、構文、DOM構造、バージョン同期、主要学習データ不変の静的検証まで。
