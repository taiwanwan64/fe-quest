FE QUEST v82 — 学習導線・進捗判定・弱点復帰監査

目的
v81までで科目A・科目Bの教材内容と問題品質を強化したため、
v82では「受講者が初日から試験直前まで使ったとき、
進捗表示と次に提示される学習が本当に一致しているか」を監査した。

主な修正

1. 科目B進捗率の重大な分母不具合を修正
旧仕様:
- bProgress / securityBProgress に保存済みの項目数だけを分母にしていた。
- そのため、アルゴリズムを1演習だけ完了すると
  1/1 = 100% とみなされる可能性があった。
- セキュリティも同様で、1シナリオ完了だけで100%扱いになり得た。
- この値が「試験準備度」「ロードマップ」「試験範囲カバレッジ」に流用されていた。

v82:
- アルゴリズムは 20 演習を分母に固定。
- セキュリティは 15 シナリオを分母に固定。
- 1/20完了は5%、1/15完了は約7%。
- 全項目完了時だけ100%となる。
- 試験準備度、ロードマップ、試験範囲カバレッジの3箇所を同じ計算へ統一。

2. 「今日の科目B」の次候補ロジックを修正
旧仕様:
- 保存済み項目だけで完了率を計算していたため、
  アルゴリズム1問＋セキュリティ1問を終えただけで
  両方100%と誤判定し、総合実戦へ進む可能性があった。

v82:
- 20アルゴリズム / 15セキュリティの実数で進捗率を比較。
- 未完了中は進捗率の低い側を優先。
- 例:
  アルゴリズム1/20=5%
  セキュリティ0/15=0%
  → 次はセキュリティ。
- 両方の基礎演習を本当に完了するまで実戦仕上げへ進まない。

3. 100分総合実戦を通常の20分枠へ自動投入しない
標準学習時間60分では、科目B枠は通常20分。
100分の科目B総合実戦をこの枠へ自動指定するのは不整合だった。

v82:
- 基礎演習完了後の日課は
  「複合問題・3問」と「セキュリティ ミニ模試」を交互に提示。
- どちらも20分枠で扱える実戦練習。
- 100分総合実戦は、受講者が明示的に総合実戦へ進む別枠のマイルストーンとして残す。
- 90分設定などで科目B割当が20分を超える場合、
  余った時間を科目A学習枠へ戻し、1日の予定合計を維持する。

4. 当日の古い学習計画をv82へ自動移行
- planVersionをv82へ更新。
- アップデート当日にすでに完了しているタスクは保持。
- 未完了タスクだけを新しい進捗判定で再計算。
- 「終えた学習が突然別タスクになる」ことを防止。

5. 科目B総合実戦の誤答から、実際の弱点分野へ直接戻す
旧仕様:
- 本番型アルゴリズム問題で間違えて「学習モードへ」を押すと、
  アルゴリズム実戦メニューへ戻るだけで、何を練習すべきかが曖昧だった。

v82:
- 問題のdomainを使い、対応するトレース演習へ直接移動。
  制御 → 二重ループ
  一次元配列 → 配列逆順
  二次元配列 → 二次元配列探索
  再帰・関数 → 再帰呼出し
  木構造 → 深さ優先探索
  オブジェクト指向 → オブジェクト状態
  リスト → 連結リスト
  スタック・キュー → スタック操作
  ビット列 → ビットマスク
  探索・整列 → 二分探索
- セキュリティ誤答は元シナリオへ戻る。

6. 弱点分析を「見るだけ」で終わらせない
- 繰り返し誤答一覧へ「この論点を復習」を追加。
- 時間を使いすぎた問題一覧へ「同じ論点をもう1問」を追加。
- クリックすると、その問題の復習問題へ直接移動。
- 弱点分析 → 復習開始を1画面で接続。

7. 表示ミス修正
弱点分析カードの
「模試平均」
は実際には平均回答秒数を表示していたため、
「平均時間」「xx秒」へ修正。

維持した内容
- 科目A問題数: 710問
- Core A: 130テーマ
- 科目Bトレース: 20演習 / 40予測ポイント
- 科目Bセキュリティ: 15シナリオ
- 本番型アルゴリズムプール: 40問
- 科目B総合実戦: 16アルゴリズム + 4セキュリティ
- 総合実戦アルゴリズム: 標準8 / 応用8 / 10分野横断
- 総合実戦セキュリティ: ログ読解2 / ケース判断2
