FE QUEST v76 — 文脈依存用語・初学者説明監査

今回の問題
- 「業務プロセス」のレッスンで、一般辞書の「プロセス＝OSが管理する実行中プログラム」が表示されていた。
- As-Is / To-Be / BPM の意味が本文に出るのに、用語欄で定義されていなかった。
- 財務諸表で B/S / P/L / C/F、ROA / ROE が説明不足だった。
- 自動用語抽出が単純な部分一致だったため、CIDR中のCI、ARP中のAR、ACID中のAC、
  クラスタリング中の「クラス」など、別概念が誤って用語欄へ出る余地があった。

v76の変更

1. 文脈依存用語辞書
- 同じ単語でもレッスンごとに定義を変えられる CORE_A_CONTEXT_GLOSSARY を導入。
- 「プロセス」は以下の文脈を区別。
  OS: 実行中プログラムの管理単位
  品質管理: 入力を成果へ変える一連の活動
  サービス改善: 測定→分析→改善→確認の活動
  サービス運用: インシデント管理等の管理活動
  業務プロセス: 申請→承認→処理→完了のような業務の流れ
- 「分散」も統計・システム構成・分散DB・DNSの文脈で分離。
- OR・IEではORを論理和ではなくOperations Researchとして定義。

2. 用語の自動抽出
- 英字略語は単純な部分一致を廃止し、英数字境界を使って判定。
- CIDR→CI、ARP→AR、ACID→ACなどの誤検出を防止。
- プロセス / 分散 / クラス / クラスタは自動抽出対象から外し、
  必要なレッスンだけ明示的・文脈的に定義。
- AIでは「クラスタ」ではなく「クラスタリング」を定義。

3. 業務プロセス
用語:
- 業務プロセス
- プロセス（業務文脈）
- As-Is
- To-Be
- BPR
- BPM
- ボトルネック

手順:
As-Is可視化
→ 問題発見
→ To-Be設計
→ ギャップ整理
→ 制度/教育/システム化
→ 効果測定・BPMで継続改善

比較表:
- As-Is = 現状
- To-Be = 目標の姿
- BPR = 抜本的再設計
- BPM = 継続的な管理改善

4. 財務諸表
用語:
- B/S / P/L / C/F
- 資産 / 負債 / 純資産
- 収益 / 費用
- ROA / ROE
- 総資産 / 自己資本

基本関係:
- B/S: 資産 = 負債 + 純資産
- P/L: 売上総利益 = 売上高 - 売上原価
- 営業利益 = 売上総利益 - 販売費及び一般管理費
- 経常利益 = 営業利益 + 営業外収益 - 営業外費用
- ROA = 利益 ÷ 総資産 × 100
- ROE = 当期純利益 ÷ 自己資本 × 100
- 問題文で利益・資産の定義が指定された場合はその定義を優先

C/F:
- 営業キャッシュフロー
- 投資キャッシュフロー
- 財務キャッシュフロー
を区別し、P/L上の利益と現金増減が同じではないことを説明。
