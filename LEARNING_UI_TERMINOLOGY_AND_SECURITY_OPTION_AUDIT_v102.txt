2. Subject B security case option-quality audit
Scope:
- 15 cases
- 45 questions
- All 45 reviewed
- 17 questions had distractor sets rewritten

Rewritten groups include:
- ransomware: backup/recovery, investigation evidence
- access control: recurrence prevention
- suspicious login: follow-up evidence
- risk management: prioritization factors
- SQL injection: parameterization and least privilege
- XSS: output controls
- password spray: compromised-account response and prevention
- unknown USB: preventive controls and safe inspection
- data exfiltration: first response, prevention and investigation scope
- password storage: password hashing alternatives
- patch management: pre-deployment considerations

Design goal:
- Wrong choices should often represent incomplete, secondary, or locally useful actions rather than obviously nonsensical actions.
- There must still be one best answer under the stated conditions.
- Correct-answer indices, question stems, explanations and hints were kept unchanged for the rewritten questions.

- C: 11
- D: 11
