FE QUEST v78 — 科目A 問題選択肢品質監査

目的
- 「正解以外が無関係で、知識がなくても消去できる」
- 「正解だけ具体的・長い」
- 「比較問題なのに、比較対象以外の第三・第四テーマが混ざる」
という問題を、科目A 710問全体の品質ゲートを使って重点修正した。

主な変更

1. 生成型の応用・見分け問題 260問を再構成
- 260/260問で誤答選択肢の選び方を変更。
- ランダムに近い同章内の別テーマではなく、比較関係・同章・同スキル・内容類似度を使って近いテーマを優先。
- そのうち 84問は、比較表を持つテーマについて「同じテーマ内の似た用語」だけで4択を構成。
- 残る 176問も、近接・混同しやすいテーマから誤答を選ぶ構造に変更。

例
システム構成:
集中処理 / 分散処理 / クライアントサーバ / 3層構造 / クラスタの役割を対応させる問題へ。

業務プロセス:
As-Is / To-Be / BPR / BPM の意味を取り違える選択肢へ。

財務:
B/S / P/L / C/F / ROA / ROE の役割を取り違える選択肢へ。

暗号:
共通鍵暗号 / 公開鍵暗号 / ハッシュを同じテーマ内で比較。

2. 比較チャレンジ 69問を再設計
- 69/69問で比較対象を明示的に2テーマへ限定。
- 旧構成のようにC・Dだけ第三・第四テーマの知識を持ち込む方式を廃止。
- 「両方を入れ替える」
- 「前半だけ正しく後半を取り違える」
- 「後半だけ正しく前半を取り違える」
の3タイプを誤答として使用。

3. 高リスク16問を個別改稿
- 基本問題 6問
- チャレンジ問題 10問

代表例:
XSS:
旧: UDP / 主キー削除 / 表示倍率 / HTMLエスケープ
新: SQLプレースホルダ / CSRFトークン / パスワードハッシュ / HTMLエスケープ

CSRF:
CSRFトークン / HTMLエスケープ / SQLプレースホルダ / CSP
のように、すべてWebセキュリティ対策として迷える選択肢へ。

SIEM:
旧: DHCP / NAT / コンパイラ / SIEM
新: IDS / IPS / ログローテーション / SIEM

CI:
旧: フルバックアップ / RFI / OLAP / CI
新: コードレビュー / 継続的デリバリ(CD) / 構成管理 / CI

プロジェクト品質:
旧: サブネット / 売上原価 / 公開鍵 / 品質
新: スコープ / コスト / リスク / 品質

4. アプリ自身の品質ゲートで発見した問題を追加修正
初回回帰で以下を検出:
- 設問文の重複
- 正解だけが明らかに長い問題 11問

修正後:
- 重複設問文: 0
- 重複選択肢を持つ問題: 0
- アプリ定義の「正解だけ明らかな長さ外れ」: 0

同じテーマ内で応用問題・見分け問題を作る場合も、
設問文自体を別表現にして「同じ問題を2回出している」印象を避けた。

- テーマ演習: Core A 130テーマ
- 章末演習: 21章 × 12問
